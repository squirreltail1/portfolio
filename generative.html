Biofeedback System For Relaxation Assistance

  • Developed a software pipeline in Python to translate heart rate and heart rate variability into control signals for a digital synthesizer.
  • Created intelligent mappings between physiological data (e.g., heart rate) and musical elements (e.g., tempo, chord complexity) to deliberately lower the user's perceived arousal.
  • Integrated hardware (ESP32 microcontroller and heart rate sensor) with software to enable real-time, bio-responsive music generation.
  • Built and tested ambient soundscapes, validating the system's effectiveness through user feedback.
