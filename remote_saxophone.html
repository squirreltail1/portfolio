remote:saxophone

  • Developed remote:saxophone, extending the Hybrid Saxophone into a Bluetooth-enabled game controller for virtual environments.
  • Engineered a hardware system using Hall-effect sensors, shift registers, and ESP32 to map saxophone key positions to digital actions.
  • Integrated a thumb-operated analog joystick for camera/mouse control.
  • Implemented firmware using ESP32-BLE-Gamepad to process binary sensor patterns into gamepad inputs.
  • Validated the prototype by controlling the game Trackmania Nations using only the instrument.
