Modelling A Bubble With Finite Schemes

  • Developed a MATLAB prototype to simulate bubble sounds using Finite-Difference Time-Domain (FDTD) methods.
  • Combined a mass-spring model (producing a frequency sweep) with a damped stiff string model to create the acoustic effect.
  • Implemented finite-difference schemes to discretize and solve partial differential equations governing string vibration and damping.
  • Achieved a short, bubbly sound by using aggressive damping and exciting the string with a time-varying frequency sweep.
